## Requirement Format

Setiap NFR memiliki ID, quality area, target, measurement method, environment,
dan owner verification. Angka baseline adalah target minimum untuk starter kit;
project turunan boleh menetapkan target lebih ketat melalui dokumen atau ADR.

## Availability and Reliability

| ID | Requirement | Measurement |
|---|---|---|
| NFR-001 | Production availability minimal 99.5% per bulan. | Uptime monitor, maintenance window dikecualikan. |
| NFR-002 | Health check mendeteksi application dan dependency failure. | Staging failure simulation dan production monitor. |
| NFR-003 | Backup database dan restore procedure terdokumentasi. | Restore drill berkala. |
| NFR-004 | Queue failure dapat diinspeksi, retry, dan replay sesuai policy. | Integration test dan operational drill. |
| NFR-005 | Incident memiliki severity, timeline, impact, mitigation, dan follow-up. | Review incident record. |

## Performance

| ID | Requirement | Target |
|---|---|---|
| NFR-010 | Endpoint aplikasi biasa mencapai P95 response time. | ≤ 500 ms |
| NFR-011 | Endpoint berat mendokumentasikan target khusus sebelum implementasi. | Per endpoint |
| NFR-012 | Query utama menggunakan index dan tidak menghasilkan N+1 yang diketahui. | Query review dan profiling |
| NFR-013 | Queue digunakan untuk pekerjaan asynchronous yang tidak perlu blocking request. | Architecture review |

### Baseline Workload

- 100 concurrent users.
- Dataset sampai 100.000 record pada entity utama.
- Endpoint CRUD/API utama dan critical user journey.
- Environment benchmark memiliki spesifikasi yang dicatat pada test report.

## Security

| ID | Requirement | Target |
|---|---|---|
| NFR-020 | Secret tidak disimpan di source code atau dokumentasi. | Environment/secret manager only |
| NFR-021 | Authentication dan authorization menggunakan contract starter kit serta AccessControl. | Security test |
| NFR-022 | Input validation mencegah injection dan invalid state. | Feature/security test |
| NFR-023 | CSRF, XSS, dan secure cookie policy diterapkan sesuai boundary. | Security review |
| NFR-024 | Audit log tidak menyimpan secret, token, credential, atau payload sensitif. | Redaction test |
| NFR-025 | Wayfinder dan Laravel Boost tidak ada dalam dependency maupun source. | Dependency scan |

## Data Consistency

| ID | Requirement | Target |
|---|---|---|
| NFR-030 | Semua table primary key menggunakan ULID. | 100% schema |
| NFR-031 | Semua foreign key menggunakan ULID dan memiliki referential integrity. | 100% relation |
| NFR-032 | Identifier tidak menggunakan integer auto-increment atau UUID. | Schema/model scan |
| NFR-033 | Migration production bersifat additive atau memiliki rollback plan. | Migration review |

## Maintainability and Testability

| ID | Requirement | Target |
|---|---|---|
| NFR-040 | Module mengikuti DDD-lite boundary, contract, dan event rules. | Architecture review |
| NFR-041 | Jalur functional utama memiliki automated test sebelum release. | Test plan gate |
| NFR-042 | Generated output bersifat deterministic dan conflict-safe. | Generator test |
| NFR-043 | Perubahan behavior memperbarui requirement atau decision terkait. | Pull request review |
| NFR-044 | Dokumentasi dapat digunakan developer dan AI tanpa instruksi lisan. | Quickstart validation |

## Operability

| ID | Requirement | Target |
|---|---|---|
| NFR-050 | Error penting memiliki structured log dan correlation ID. | Log inspection |
| NFR-051 | Application, database, cache, queue, dan storage health dapat diamati. | Staging verification |
| NFR-052 | Release memiliki rollback procedure yang dapat dijalankan. | Release drill |
| NFR-053 | Audit log disimpan minimal satu tahun. | Retention policy review |

## Accessibility and UX

| ID | Requirement | Target |
|---|---|---|
| NFR-060 | Halaman dan component starter kit memenuhi WCAG 2.2 Level AA. | Automated scan + manual review |
| NFR-061 | Semua critical flow dapat dijalankan dengan keyboard. | Manual keyboard test |
| NFR-062 | UI menggunakan semantic HTML, focus state, label, dan error message yang jelas. | Component review |
| NFR-063 | Layout responsive untuk viewport yang didukung. | Browser/device test |

## Compatibility

### Backend

- PHP 8.4+
- Laravel 13

### Frontend

- React
- TypeScript
- Inertia.js
- Vite
- Tailwind CSS
- shadcn/ui

### Browser

Baseline mendukung versi terbaru dan satu versi sebelumnya dari:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Apple Safari

Project turunan dapat menambah browser melalui compatibility decision sendiri.

## Verification Rules

QA memverifikasi behavior dan quality target melalui test plan. DevOps
memverifikasi availability, logging, deployment, recovery, dan restore pada
staging. Developer memverifikasi schema, migration, model, DTO, route, event,
fixture, API response, dan generated output.

NFR dianggap lulus hanya jika hasil verifikasi memiliki environment, timestamp,
tool, input workload, dan evidence yang dapat direview.
