# KelasRombel

Module `Academic/KelasRombel` adalah skeleton awal untuk capability
`Kelas / Rombel / Kurikulum`.

Scope runtime belum berisi schema atau route aktif. Increment berikutnya akan
menentukan public contract readiness sebelum data foundation dibuat, agar module
ini tidak mengambil model Infrastructure dari `Organization`, `AcademicPeriod`,
`Pesantrian/Santri`, atau `HumanResource` secara langsung.

Dokumentasi kerja: `docs/modules/Academic/KelasRombel/`.
