## Command Principles

- Command memakai Laravel Artisan colon syntax.
- Nama dan argument harus deterministic serta mudah dipahami AI.
- Command memvalidasi input sebelum side effect.
- Error mengembalikan exit code non-zero dan remediation message.
- Generator fail-safe; overwrite hanya dengan `--force`.
- `--dry-run` tidak boleh mengubah filesystem atau database.
- Command baseline mendukung `--json` untuk machine-readable output.
- Output tidak boleh menampilkan secret, token, credential, atau payload sensitif.
- Command yang menghasilkan side effect wajib memiliki audit/verification impact.
- Semua command didokumentasikan dengan argument, option, output, exit code, dan test.

## Baseline Module Commands

### `module:make`

Membuat module/submodule lengkap.

```bash
php artisan module:make AccessControl --domain=System --force --yes --json
php artisan module:make UserManagement --domain=System --force --yes --json
php artisan module:make SystemSetting --domain=System --dry-run --json
php artisan module:make AuditLog --domain=System --force --yes --json
```

Options:

- `--dry-run`: tampilkan rencana file tanpa menulis.
- `--force`: wajib untuk operasi mutasi; tidak membuka overwrite pada Phase 3.
- `--yes`: menandai persetujuan non-interactive dan wajib digunakan bersama
  `--force`.
- `--profile`: profile generator, saat ini `default-v1`.
- `--json`: menghasilkan output machine-readable.

Output minimum: module path, namespace, manifest, file created/skipped/changed,
warnings, dan next steps.

### `module:list`

```bash
php artisan module:list
```

Menampilkan module discovered/registered dengan name, version, status, path,
dependency, dan health. Privileged metadata hanya terlihat sesuai authorization.

### `module:discover`

```bash
php artisan module:discover
php artisan module:discover --json
```

Menjalankan discovery read-only. Module invalid diisolasi dari module valid dan
diagnostic dikembalikan dengan exit code yang sesuai.

### `module:validate`

```bash
php artisan module:validate
php artisan module:validate --json
```

Memvalidasi manifest module secara global tanpa mengubah file. Validasi target
module spesifik belum tersedia pada command saat ini.

## Baseline Support Commands

### `starter:verify`

Memverifikasi Laravel, PHP, starter kit, Inertia, React, TypeScript, Vite,
Tailwind, shadcn/ui, Ziggy, PostgreSQL, Redis, approved package, dan forbidden
dependency.

### `starter:diagnose`

Menampilkan environment, module health, cache, queue, storage, dependency, dan
configuration diagnostic tanpa secret.

### `starter:health`

Mengembalikan health status application dependency untuk local, CI, dan staging.

## Development Commands

Command berikut dapat tersedia sebagai Laravel-native command tetapi bukan
semuanya wajib pada baseline generator:

```bash
php artisan event:make UserCreated
php artisan listener:make RecordUserAudit
php artisan policy:make UserPolicy
php artisan docs:generate
php artisan stub:publish
```

`crud:make`, `feature:make`, `resource:make`, dan `api:make` bukan baseline
pertama. Command tersebut hanya boleh ditambahkan setelah module generator dan
vertical slice stabil melalui specification/ADR baru.

## AccessControl and User Commands

Command berikut harus memiliki authorization, validation, idempotency policy,
dan audit event sesuai capability:

```bash
php artisan permission:sync
php artisan user:impersonate {user}
php artisan user:impersonate-exit
```

Impersonation command boleh digunakan di production, wajib meminta reason,
menolak target `SuperSystem`, dan
menjaga actor context. Jika digunakan melalui API/UI, command tetap mengikuti
domain contract yang sama.

## SystemSetting Commands

Hanya `SuperSystem` yang boleh menjalankan command mutasi setting.

```bash
php artisan system-setting:list
php artisan system-setting:get {key}
php artisan system-setting:set {key} {value}
php artisan system-setting:validate
```

`system-setting:set` langsung aktif setelah validation, membutuhkan reason, dan
mencatat before/after, actor, correlation ID, serta audit event. Secret tidak
boleh muncul pada output.

## Machine-Readable Output

Semua command baseline mendukung:

```bash
php artisan module:validate --json
php artisan module:list --json
php artisan starter:verify --json
```

Default output tetap human-readable. JSON output wajib memiliki `success`,
`code`, `message`, `data`, dan `diagnostics` bila relevan. Secret, token,
credential, dan sensitive payload dilarang pada kedua format.

## Exit Codes

| Code | Meaning |
|---:|---|
| 0 | Success |
| 1 | General failure |
| 2 | Invalid argument/validation |
| 3 | Authorization denied |
| 4 | Conflict or unsafe overwrite |
| 5 | Dependency/module invalid |
| 6 | Environment/dependency unavailable |

## CI Usage

CI minimum menjalankan:

```bash
php artisan starter:verify
php artisan module:validate
php artisan module:discover
php artisan test
```

Command harus non-interactive pada CI; gunakan option eksplisit dan fail-safe.

## Testing Requirements

- Unit test argument parser dan validation.
- Feature test authorization dan exit code.
- Filesystem test untuk dry-run, conflict, force, dan rollback behavior.
- Integration test discovery, registry, cache, database, dan queue.
- Security test secret redaction, SuperSystem, scope, dan impersonation.
- Snapshot/contract test untuk output penting yang dipakai CI atau AI.
