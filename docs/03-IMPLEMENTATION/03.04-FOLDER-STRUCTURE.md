## Database and Routes

```text
database/
|-- factories/
|-- migrations/
`-- seeders/

routes/
|-- web.php
|-- api.php
`-- console.php
```

Module-owned migration, factory, seeder, dan route berada di module directory;
root directory hanya berisi registration/entry point jika diperlukan Laravel.

Upload/media memakai storage abstraction dan Spatie Media Library; jangan
menyimpan user upload sensitif langsung pada public path.

## Folder Ownership Rules

- Folder hanya memiliki satu owner yang jelas.
- Shared folder tidak boleh menjadi tempat business logic acak.
- Generator wajib menghasilkan struktur sesuai dokumen ini.
- Perubahan struktur membutuhkan update generator, coding standard, test, dan ADR
  bila mengubah boundary.
- Jangan membuat folder alternatif dengan nama yang sama tetapi ownership berbeda.

## Confirmed Structure Decisions

- Migration, factory, dan seeder tetap module-local pada
  `app/Modules/{Domain}/{Submodule}/Database/`.
- Permission identity module tetap module-local pada
  `app/Modules/{Domain}/{Submodule}/permissions.php`.
- Frontend page entry point berada pada
  `resources/js/pages/System/{Module}/pages/`.
- Root `database/` dan root `resources/js/pages/` hanya menjadi entry point atau
  foundation Laravel; business implementation tetap berada pada owner module.
