## Purpose and Scope

Source of truth metadata module. Dokumen ini menjadi kontrak implementasi dan tidak menambah business
requirement baru. Implementasi mengikuti baseline 00–05, ADR-0001, dan ADR-0002.

## Boundary and Contract

module.json, status, version, provider, dependencies, permission source.

Input tervalidasi sebelum side effect. Output typed, deterministic, dan tidak
boleh memaksa caller mengakses private implementation. Semua identifier,
correlation ID, actor ID, job ID, dan fixture menggunakan ULID.

## Rules

- Cross-module communication memakai public contract, DTO, atau typed event.
- Module invalid diisolasi; module valid lain tetap berjalan.
- Mutation sensitif memiliki authorization, audit, dan correlation ID.
- Wayfinder dan Laravel Boost dilarang pada dependency, source, config, dan output.
- Secret, token, credential, password, dan sensitive payload tidak masuk output,
  log, diagnostic, template, cache, atau generated artifact.
- Failure menghasilkan error code stabil, message actionable, dan context sanitized.

## Baseline Integration

Framework package menyediakan capability reusable untuk module generator, registry, discovery, console, stub, template, extension, package, dan versioning. Business logic tetap berada pada app/Modules.

SystemSetting menyimpan runtime configuration global. Schema, default, behavior,
dan registration tetap dimiliki module asal. Hanya SuperSystem yang boleh
mengubah setting; perubahan aktif setelah validation dan wajib diaudit.

## Failure and Recovery

- Validation failure berhenti sebelum side effect.
- Runtime module failure menonaktifkan module tersebut, bukan seluruh bootstrap.
- Filesystem operation memakai staging dan atomic promotion bila relevan.
- Redis/cache failure memakai safe default dan menghasilkan diagnostic.
- Retry hanya pada operation idempotent atau dengan idempotency key.
- Recovery evidence dicatat pada log, audit, test, atau release record.

## Acceptance Criteria

- Contract, namespace, dependency, dan lifecycle test lulus.
- Happy path, negative path, authorization, dan failure path tersedia.
- ULID, correlation ID, redaction, dan forbidden dependency test lulus.
- Output deterministic dan dapat diverifikasi melalui console atau diagnostic.
- Documentation, README, test, dan cross-reference tersedia.
- CI quality, security, dan build gate dari 03.10 lulus.

## Verification

Developer menjalankan unit, feature, integration, dan contract test relevan. QA
memverifikasi acceptance dan critical flow. DevOps memverifikasi health, log,
cache, queue, deployment capability, dan rollback impact. Evidence direferensikan
pada task plan dan release record.
