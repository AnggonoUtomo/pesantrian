# Daftar Module

Dokumen ini menjadi indeks ownership dan dependency. Detail module berada pada
`modules/{Domain}/{Module}/`.

| Domain     | Module     | Tanggung jawab     | Dependency utama          | Status  |
| ---------- | ---------- | ------------------ | ------------------------- | ------- |
| `[Domain]` | `[Module]` | `[Tanggung jawab]` | `[Module lain/tidak ada]` | Planned |

Saat menambah module, catat tanggung jawab tunggal, dependency nyata, dan
statusnya. Jangan menambahkan dependency untuk kebutuhan hipotetis.

Status yang digunakan: `Planned`, `Active`, `Deprecated`, atau `Disabled`.
