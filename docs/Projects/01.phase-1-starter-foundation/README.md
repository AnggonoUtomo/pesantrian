## Tujuan

Memastikan fondasi Laravel starter kit siap dipakai sebelum membangun
`packages/StarterKit` dan module generator.

## Ruang Lingkup

- Memeriksa versi dan stack utama.
- Memeriksa package baseline dan dependency terlarang.
- Memeriksa database, Redis, cache, queue, session, storage, dan ULID.
- Menyediakan verification command bila belum tersedia.
- Menjalankan quality gate dan menyimpan evidence.

## Di Luar Ruang Lingkup

- Membuat module bisnis.
- Membuat `module:make`.
- Membuat registry atau package `packages/StarterKit`.

## Aturan Kerja

Setiap task dikerjakan bertahap. Checklist ditinjau sebelum dan sesudah task.
Task hanya boleh ditandai selesai jika acceptance criteria dan evidence sudah
tersedia.
