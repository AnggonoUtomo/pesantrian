# Work Item Lintas Module

Folder ini hanya untuk pekerjaan signifikan yang dimiliki lebih dari satu
module atau menyentuh framework dan beberapa module sekaligus.

```text
work-items/{nama-pekerjaan}/
|-- README.md
|-- plan.md
`-- tasks.md
```

Gunakan nama `kebab-case`. Sebutkan owner setiap perubahan dan dependency antar
increment. Jika pekerjaan hanya dimiliki satu module, simpan di
`modules/{Domain}/{Module}/work-items/`.
